fastsone capture-LW-ubuntu 2.6.1 — 经典桌面版

面向 Ubuntu 的独立截图软件，参考 FastStone Capture 的经典工作流程：
紧凑悬浮工具栏 → 输出目标 → 多标签编辑器 → 绘图。
使用自主绘制的图标，没有包含 FastStone 的程序或图标素材。

2.6.1 设置窗口（2026-11-08）
设置跟随系统主题配色，文字随桌面字号缩放。快捷键分组加粗，图标列表行距加大。

2.6 编辑器与个性化设置（2026-11-08）
在编辑区按住 Ctrl 并滚动滚轮，可在 10% 至 800% 间缩放。普通滚轮用于浏览图片。
设置 → 快捷键支持修改全局与编辑器按键，留空停用。设置 → 图标布局支持拖动、上下移动与显示开关。
点击应用后立即生效，设置会保存到个人配置。设置按钮始终可见，两个工具栏可分别恢复默认布局。

2.5 识字质量优化（2026-10-29）
识别不确定时换尺寸复查，并按可用情况调用官方高精度模型；不会猜测或自动改写字符。
识别有清晰间隔的两栏文字时，按先左栏、后右栏的顺序输出。
不确定结果仍复制到剪贴板，同时提示核对原图；空白或失败时保留原剪贴板。
去掉无用空白边缘，保留必要边距，支持浅色/深色背景，避免盲目放大所有中文。
中英文高精度复查模型可单独安装，日常识别在本地运行。
新机器可选安装：/usr/bin/python3 tools/install_ocr_models.py（下载约28MB，固定版本、SHA-256校验）。
模型单独存放在 ~/.local/share/fastsone-capture-lw-ubuntu/ocr-models/，不混入源码安装包。
未安装可选模型时仍能使用系统/个人安装中的普通 Tesseract 模型。
27张未参与调参的合成验证图：总体字符准确率81.66%→98.21%；
其中24张单栏96.74%→97.59%，3张两栏（含阅读顺序）38.41%→100%。
算法按Unicode字符编辑距离计错，忽略空白但保留标点和大小写。
这是指定样例上的结果，不代表所有真实截图的准确率；小字、形近字、数字/字母混淆和标点仍需核对。
详细样例、逐图原文和结果可通过 tests/ocr_benchmark.py 重现。

2.4 截图识字（2026-10-28）
F4 → 鼠标框选文字 → 松开鼠标 → 中英文识别 → 自动复制到剪贴板。
Ctrl+V 粘贴；Esc 或右键取消。此流程不受截图“输出目标”影响。
识别在本机后台进行，不上传截图；截图像素通过内存传给识别引擎，不保存临时图片。
成功后显示通知；没识别到文字或发生错误时保留原剪贴板。识别期间避免重复任务。
F4 由 Capture 提供，登录自启后有效，不需要打开 gImageReader 主窗口。
引擎为 Tesseract，语言为 chi_sim + eng；对小字号适度放大，避免过度放大中文。
文字识别可能有错字，重要内容请核对。复杂表格、手写字和模糊文字效果有限。
标准依赖安装命令：sudo apt install tesseract-ocr tesseract-ocr-chi-sim tesseract-ocr-eng
也支持本机个人目录中的 ~/.local/share/gimagereader-lw/runtime/ 引擎。
gImageReader 是另行安装的图形识字工具，用于图片/PDF、校对和批量识别，未打入本软件源码包。

2.3 稳定性与整理（2026-10-28）
图片和设置先完整写入临时文件，再替换目标，避免编码或写入失败破坏已有文件。
录像也在封装成功后才替换目标；启动失败正确清理状态、计时器和监听。
失败时非空录像临时文件保留并提示路径，方便尝试恢复。
PNG、TIFF、WebP 保留透明背景；JPEG、BMP 将透明区域铺成白色。
补充自动添加扩展名后的覆盖确认；打开已有图片正确关联文件名和保存状态。
编辑器缓存已完成的标注，减少缩放、重绘及绘制预览时的重复计算。
各标签的缩放选择独立同步；样式不再随窗口创建重复注册。
验证设置类型，损坏设置回退默认值；工具栏位置延迟写入，减少频繁写盘。
修复部分窗口管理器在截图结束后把红条移到屏幕中央的问题。
升级保留自动启动选择及正在运行的编辑会话。
测试集中到 tests/，在独立 Xvfb 桌面运行并自动删除测试产物。

2.2 工具栏与快捷操作
工具栏闲置约1.2秒后自动向上收起，在当前屏幕的可用区域顶边保留6像素高、宽度为展开工具栏三分之一的红条。
鼠标移入红条即可展开；菜单、设置对话框打开或截图期间不会自动收起。
F3 直接启动矩形截图，工具栏收起时同样可用；Esc 取消。
工具栏显示“目标：到编辑器 / 到文件夹 / 到剪贴板…”及当前选项。
“到文件夹”自动保存 PNG；“选择目标文件夹…”可更改目录并切换到该目标。
“到文件…”每次弹出保存对话框；另外保留到绘图、到打印机及同时复制选项。
升级时保留正在运行的编辑会话，避免丢失截图；保存并退出后重新打开新版。

2.1 修复记录
修复截图选区的鼠标事件接收位置，解决拖选不响应、截图后点击不灵。
补齐 Esc 取消；完成、取消、隐藏、关闭和异常时均释放鼠标与键盘。
固定区域、窗口点选、取色在松开鼠标后完成，防止吞掉下一次点击。
过小选区自动取消；获取输入失败会退出，避免全屏遮罩残留。
关闭保存提示框不再丢弃未保存截图；输入框快捷键不再误触发图片操作。
修复画布外马赛克/模糊边界、切换绘图工具与裁剪后的状态问题。
滚动截图及设置保存异常会恢复工具栏和截图状态。
使用真实 X11 鼠标键盘事件，验证八种选区模式 Esc、拖选、右键、
重复截图及异常退出，并确认结束后的第一次点击能被另一测试程序接收。
已回归截图、编辑、导出、真实滚动拼接、录屏暂停/继续与文件解码。

运行环境
Ubuntu 24.04 x86_64、系统 Python 3.12、GTK3、X11。
本机已验证；Wayland 会话请切换为 Ubuntu on Xorg。
录像使用本机已有的 GStreamer 组件，无需安装 FFmpeg。

安装及启动
在解压后的软件文件夹打开终端：
  /usr/bin/python3 install.py
个人安装，无需 sudo。首次安装添加应用菜单并启用登录后启动，升级保留原选择。
如果旧版仍在运行，安装后请保存截图并退出，再从应用菜单重新打开。
安装位置：~/.local/share/fastsone-capture-lw-ubuntu/
也可直接运行源文件：/usr/bin/python3 capture.py
查看版本：/usr/bin/python3 capture.py --version
应用菜单搜索 fastsone capture-LW-ubuntu 可重新打开。

经典悬浮工具栏
拖动顶部标题移动位置。按钮依次为：
打开图片、活动窗口、窗口/对象点选、矩形区域、手绘区域、
整个屏幕、滚动窗口、固定尺寸区域、屏幕录像机、输出、延迟、设置。
鼠标停留可查看名称；Esc 或右键取消截图。
闲置时向上收起为红条，移入展开。F3 随时启动矩形截图。
窗口点选按顶层窗口的边界捕获，不识别应用内部的各个控件。
固定区域尺寸在“设置 → 捕获与保存”中配置。
取色器和屏幕标尺在设置菜单或编辑器“工具”菜单中。
标尺显示选区宽、高和对角线像素数；取色后颜色值自动复制。

输出菜单
目标菜单：到编辑器、到文件夹、到剪贴板、到文件、到绘图、到打印机。
目标按钮直接显示当前选择。到文件夹自动保存 PNG，可在菜单中选择/打开目录。
“同时复制到剪贴板”可为其他输出目标附加复制动作。
到文件会打开保存对话框并保留编辑标签，取消时截图仍可编辑。
自动保存位置由设置指定，默认 Pictures；文件名包含微秒避免覆盖。

多标签编辑器
每张截图在同一窗口的新标签中打开；标签可拖动排序，× 关闭。
关闭编辑器窗口只隐藏窗口、保留截图；退出整个软件时逐张提示保存。
顶部提供打开、保存、绘图、标题、边缘、尺寸、旋转、裁剪、复制、
打印、贴图、撤销/重做；右上角设置缩放比例，放大后可滚动查看。
“图像”菜单另有水平翻转和灰度。
支持 PNG、JPEG、BMP、TIFF、WebP、PDF 导出，保存时输入相应扩展名。
Ctrl+S 保存，Ctrl+Shift+S 另存为，Ctrl+C 复制，Ctrl+V 导入剪贴板图片，
Ctrl+O 打开，Ctrl+W 关闭当前标签，Ctrl+Z / Ctrl+Shift+Z 撤销/重做。
最多保留30步图像或标注修改。

绘图
先点击“绘图”进入标注模式；点击“完成绘图”返回编辑器。
支持选择/移动、箭头、直线、矩形、椭圆、画笔、中文文字、气泡、
高亮、聚光灯、模糊、马赛克、编号及裁剪。
文字/气泡/编号单击添加；其他工具按住左键拖动。
选择/移动工具可点击标注边界附近并拖动，Delete 删除选中的标注。
颜色、线宽、字号可调；保存为图片后标注会合并到图片中。
贴图窗口置顶，Esc 或关闭按钮关闭。

滚动长截图
1. 点“滚动窗口”，只框选正在滚动的内容区域。
2. 避开固定标题栏、侧栏、悬浮按钮、滚动条及粘性页眉。
3. 点击“开始滚动”；软件向该区域发送向下滚轮事件并自动截图拼接。
4. 保持目标窗口不变、不操作鼠标。底部内容不再变化时自动完成。
5. 控制窗口中的“完成”保存当前拼接结果；“取消”丢弃本次结果。
软件先匹配实际重叠部分再拼接。无法可靠匹配时会提示并保留已有部分。
安全上限为35帧或24000像素高度，超长内容请分段截取。
不保证所有网页、动画页面、虚拟列表和固定元素页面都能自动拼接。

屏幕录像机
可录全屏或框选区域，15 FPS、WebM（VP8）视频。
声音可选不录音、麦克风或系统声音（取决于当前音频设备）。
控制窗口支持暂停、继续、停止并保存。Ctrl+Alt+R 也可停止。
停止后等待文件封装完成，不要直接杀进程。错误会显示说明。
全屏录像会包含可见的录像控制窗口；选区录像可将控制窗口移出选区。
不支持 MP4/WMV 导出、摄像头叠加、定时录制及视频剪辑。

快捷键
F3：快速启动矩形区域截图（收起时可用）。
F4：框选屏幕文字，中英文识别后自动复制（收起时可用）。
优先尝试 FastStone 风格：Ctrl+Print 矩形、Alt+Print 活动窗口、
Print 全屏、Shift+Print 窗口点选。Ubuntu 可能已经占用这些按键。
备用键：Ctrl+Alt+A 矩形，Ctrl+Alt+F 全屏，Ctrl+Alt+W 活动窗口。
Ctrl+Alt+R 打开录像机或停止当前录像。
“设置 → 快捷键”可更改上述默认按键，点击应用后生效。
格式示例：<Control>Print 或 <Control><Alt>a。

自动启动
设置菜单或设置对话框可打开/关闭“登录后自动启动”。
自动启动项：~/.config/autostart/fastsone-capture-lw-ubuntu.desktop
软件与个人设置位于个人目录，无需管理员权限。

验证与边界
本机已实测六种非滚动截图、手绘透明区域生成、绘图、移动/删除标注、
裁剪撤销、剪贴板与自动保存、六种格式导出、标签、缩放及备用全局快捷键。
设置、录像选项、打开/保存、改尺寸、标题及打印对话框已验证显示和取消。
在真实可滚动窗口验证了自动滚轮和拼接；验证了实际录像、暂停、继续、
停止封装以及录制文件可解码。声音输入与多显示器/高DPI组合未全面测试。
本版未实现 FSC 可编辑工程、Office/邮件/FTP输出、扫描仪、
屏幕放大镜、复杂效果和视频编辑，不能替代 FastStone 的全部功能。
截图与录像在本机处理；仅“打开软件帮助”等用户自行操作才涉及外部网页。
